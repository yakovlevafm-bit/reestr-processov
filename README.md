# Реестр процессов

Инструмент для органа власти: какие процессы брать в оптимизацию, в каком порядке и на каком основании.
Загружает реестр процессов ведомства, собирает факты с источниками, отбирает процессы по каскаду,
ведёт паспорта, анкеты подразделений, гипотезы улучшения, короткий список на обследование и обзоры
эффекта после внедрения.

Без внешних пакетов: Node.js 24, данные — файлы в каталоге `data/` (JSON или SQLite) на компьютере ведомства.
Интерфейс — в браузере, по локальному адресу.

## Принципы

- **Каждая оценка прослеживается до факта, источника и правила.** Значения из реестра — «предложение»,
  подтверждённые экспертом с основанием — «подтверждено»; оценки по типу процесса остаются пометкой.
- **Нет данных — «сначала замерить», а не отсев.** Процесс без трудозатрат не выпадает из рейтинга,
  а получает список того, что нужно замерить.
- **Уровень доказательности вычисляется, а не назначается:** PRE → INTERVIEW → VERIFIED.
- **ИИ предлагает, человек подтверждает.** Подключение к ИИ-шлюзу необязательно; без ключа ничего никуда не уходит.
- **Ядро не знает о ведомстве.** Названия, подразделения, типы процессов, функции по положению,
  отраслевые слова — в профиле `profiles/<id>/`. В поставке — вымышленный демо-профиль.

## Быстрый старт

```bash
node reestr.js demo
```

Загружает пример: вымышленный комитет по культуре и туризму, 8 процессов. Затем:

```bash
node reestr.js serve
```

и откройте http://localhost:8650. Автотесты:

```bash
node reestr.js test
```

## Своё ведомство

1. Создайте профиль `profiles/<id>/` — см. [docs/ПРОФИЛЬ.md](docs/ПРОФИЛЬ.md): название и подразделения,
   типы процессов с правилами распознавания, функции из положения о ведомстве, отраслевые слова паспорта.
2. Положите реестр процессов в xlsx по шаблону ОГВ (заголовок в строке 8, «Название процесса» в колонке D;
   колонки описаны в `lib/registry_import.js`).
3. Загрузите: `node reestr.js import <файл.xlsx>`. Профиль выбирается переменной `REESTR_PROFILE`,
   ключом `profile` в `data/config.json` или автоматически, если профиль один.
4. Дальше по кругу: анкеты подразделений (`anketa2`, `anketa2-import`), опросник владельцев (`opros`),
   подтверждение фактов в карточках, отбор по каскаду, короткий список, гипотезы, базовая линия, обзоры.

Все команды: `node reestr.js` без аргументов или заголовок `reestr.js`.

## Что внутри

| Раздел интерфейса | Что показывает |
|---|---|
| Портфель | группы приоритета по методике v1.1: подтверждённые кандидаты, «сначала замерить», блокеры |
| Процессы | реестр с паспортом (вид, поток, получатель), фильтры, выгрузка в Excel |
| Отбор (каскад) | основная схема отбора: гейты → получатель и объём → проблема → поток → реализуемость, линия мощности |
| Короткий список | прошедшие отбор, не больше мощности обследования; чек-лист этапов обследования |
| Обзоры эффекта | базовые линии проектов, сроки обзоров через 3 и 12 месяцев, эффект к базовой линии |
| Карточка процесса | факты с источниками, паспорт, оценки, доказательность, гипотезы и их реализуемость, базовая линия |
| Методика | правила расчёта как они работают в этой версии |

Методика целиком — [docs/МЕТОДИКА.md](docs/МЕТОДИКА.md).

## Структура

```
reestr.js            команды (импорт, анкеты, экспорт, тесты, сервер)
server.js            веб-интерфейс, без фреймворков
lib/                 ядро: хранилище, импорт, методики, паспорт, каскад, доказательность, гипотезы, обзоры
profiles/<id>/       профиль ведомства; demo-kultura — пример
tests/               автотесты ядра, одновременная запись, сквозная проверка на демо-профиле
docs/                методика и описание профиля
data/, export/, import/   данные ведомства — не в репозитории
```

Хранилище: `REESTR_DATA` (каталог данных), `REESTR_EXPORT` (выгрузки), `REESTR_STORAGE=json|sqlite`
(перенос: `node reestr.js storage migrate`). Выпадающие списки в анкетах Excel и защита ключа ИИ-шлюза
используют PowerShell — на других ОС эти два шага пропускаются, остальное работает.

## Состояние

Применяется в одном региональном министерстве: 276 процессов, анкеты подразделений, показатели потока по СЭД,
план оптимизации на год. Профиль этого ведомства и его данные в репозиторий не входят.
